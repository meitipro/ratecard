# Archive: the v0.3 deployment

Records of the first deployment, `0x8E07F4eDd2C9F457F7148356720634a2bCeab2cF`, which ran on the GenVM v0.3 runner. Studio Next removed that runner, and reads of the contract now fail with "execution failed". The contract was redeployed on the v0.4 runner and every record in `eval/` and `docs/` was produced again against the new address. These files are kept so the earlier results stay checkable in the explorer's history, and nothing here is cited as a result of the current deployment.
